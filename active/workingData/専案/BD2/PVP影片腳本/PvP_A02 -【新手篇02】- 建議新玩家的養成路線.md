# 【教學類-影片】


開始前，我先說些遊戲常見的「專有名詞縮寫」，方便新手理解

主線10 = 主線第10章，沒說難度通常是指簡單難度
魔獸10 = 魔獸討伐者難度10
公會10 = 公會王難度10

末日 = 末日之戰
鏡戰 =  鏡中之戰
黃金 = 黃金競技場

爬塔，要看是什麼塔

塔有五種：
救贖、傲慢、慾望、忌妒、憤怒

傲慢塔又稱六層塔，因為它只有六層，爬一次就能領每日獎勵，越早拿滿越好

救贖塔，每月重製，只要有打過一場，就能領全服獎勵，推薦每期至少打到LV5或以上

剩下三個塔，吃隊伍練度，可以先放著，未來有時間在爬就好

接下來是我個人的理解，供大家參考
我把新手期分三個階段，各階段有不同目標：

S1-新手期，純新手時期

主線，第八章打完前，都屬於這個階段。

- 主線，第三章打完
- 開啟功能
	- 鏡中之戰(每日要打滿40酒，可40倍打一場就好)
	- 公會 (可以開始找了，公會有養成資源)
		- 對於新手，公會可以先找休閒公會，或是願意帶新手的公會。
		- 如果是後者，很高概率會希望你先練輔助或以此當門檻，才讓你加入，原因後面會說明。
		- 運營好的公會，基本會有提供新手可以詢問問題的管道，像是QQ群、DC群、LINE群...這種，那新手也可以透過這方法請教別人。

- 主線，第四章打完
- 開啟功能
	- 末日之戰 (打一次，確保每日拿資源就好)
	- 傲慢之塔 (先打一次，後面有能力時，越早完成1萬分越好，每天6顆古代水晶)

- 黃金競技場(每週三結算，至少100場領任務獎勵)

S1-新手期，中間時期

主線，第八章打完~第十四章打完前，都屬於這個階段。

［第九章會遇到第一次數值膨脹］
主要門檻：角色等級、主要角色的裝備等級不夠

- 開啟功能
	- 救贖之塔 (至少每月打一次，有全服獎勵，推薦打到LV.5)

> 遇到膨脹，我個人推薦大家可以去『借別人角色』，去推進度。
> 「借角色」這塊，後面補充。

- 魔獸5
- 公會王：基本能打3~5

S1-新手期，準結束期

主線，第十五章打完前，都屬於這個階段。

［第十五章會遇到第二次數值膨脹］
主要門檻：角色陣容組合、主要角色的裝備等級不夠

- 魔獸5以上，8以下
- 公會王：3~7

進入一般玩家期 ：

S2-一般玩家-早期
- 主線，全推完
- 魔獸10以前　

S3-一般玩家-中後期
- 魔獸10　（至少要練兩隊，有裝備更好）
- 開始有多餘資源，可選擇，下個主要遊玩路線
	- 1. PVP 鏡中之戰 (目標鑽石)
	- 2. 公會戰
	- 3. 魔獸15

裝備的部分:
UR(專)>UR4>SR4>UR2>SR > R > N

UR(專)相比UR4，多一個詞綴，大概是多10~20%的提升，通常是一班玩家中期，開始追數值才考慮的，新手前面的抽卡量可能不夠，建議先抽關鍵角色，提昇會比抽專武來的比較好。

補充SR4是因為前期就能得到。

「合約之戰」，一樓辦公室往左上的出口，往外走打開下水道蓋子，進去下水道後走到底有個寶箱，裡頭有兩件 SR4可以先將就用。

這邊做點補充、

三周年這次，願意花點小錢的。

MEGA MASTER 店長禮包 可以買三包。
這禮包全都會用到，對於新手最缺的資源，是完整的一套傳說裝備(UR4)，那買三包就是三套。
那三包至少是新手無課玩家三個月到半年的裝備進度（合裝備要看運氣）。

MEGA SALE 三天期限的聖石禮包，也可以考慮一併購買，共75000顆聖石，約等於半年無課玩家的聖石量(潛力要用)。

這兩個是小課、微課，都極力推薦必買的。

推薦養成的角色順序：

（推圖階段）

個人建議：
主C先練一隻推圖用，其他都先練通用輔助。
進入中期時，能更快轉換角色去打其他PVE關卡。

會這樣推薦的原因跟傷害公式有關，但這邊大家有個概念就好。後面我會再細談傷害公式。

【派大星梗圖：我不知道還要考試】

目前只要先知道，最基本的是：

- 傷害 = 基本傷害 x 輔助加成

由於有剋屬增傷的問題，這東西再往下拆分：

- 傷害(上限) = ［克制屬性-傷害 x 克制屬性用-輔助］ x 其他通用的輔助)

所以，如果傷害上限要高：

1. 該屬性的主C
2. 該屬性的專輔
3. 通用輔助

那因為每期魔獸王都會換屬性，大部分狀況，我們都會建議先練通用輔助，確保你不論王換哪種屬性，都能有個保障的傷害。

還有個好處是，公會王跟推圖可以借角色，大部分人這階段沒資源練各種屬性的主C，但你可以借別人大腿的C，只要自己的輔助練度不低，就能打比較高等級的公會王，那以後找公會只要不是0.1這種拚最高上限的公會，都比較好達到別人公會低標的門檻，更方便多農點資源成長。

礙於影片時長的問題，為何推薦的原因會跟詳細的傷害公式，另開一期講解，目前只要先知道是這幾隻角色即可，可以參考一下。

補充、怎麼借朋友/公會的角色

首先要先加對方好友，並且請對方在好友畫面，輔助角色上面，放上他要借別人的兩隻角色。

對於被借角色的人，每有人借一次，他能獲得2個裝飾幣，當日上限是20個，同種類型的關卡，同個人最多借三次。如果你們兩個都有想要刷，也可以互借彼此的角色。

當你要打魔獸活動關跟推主線時，進入戰鬥畫面時，點選左下角的換角色，上面有個握手的符號是表示選擇使用好友的角色，點下去，你就能選好友的角色來使用。

對於新手，基本是跟別人借好推圖的主C推圖，加速推圖功效。
練好角色只想互刷的人，基本是借別人練好的輔助。

（魔獸階段）

魔獸不能借朋友的角色，所以主C只能自己來。

但正如前面提的，推薦先練輔助，再練主C，前面能打的魔獸等級，會稍微低一點。
但後續輔助有拉起來後，每期只再多拉一兩隻C，基本就能穩定魔獸10。
這時候你就能自行選擇後續路線了。

如果想更多點資源，再來目標可以放每期魔獸15(統稱魔獸絕望)，能多賺些洗鍊裝備的粉末。
或者加入公會戰、鏡中之戰。

這期概念就講到這，希望能幫你們解決些疑惑。
