# Google Sheet 使用說明

## 檔案位置

已經幫你直接在 Google Drive 建好了，一個檔案兩個分頁，公式、下拉選單、狀態顏色都已經設定好：

**LeetCode學習追蹤表**：https://docs.google.com/spreadsheets/d/10pFFKjyvGgBdGJWdoWSjlmV_pASx3MykvmXwl2LPMv8/edit

- `總覽表` 分頁：一題一列，EF / n / Interval 三格公式已串好，會自動抓 `複習紀錄表` 最新資料
- `複習紀錄表` 分頁：每次複習一列，狀態欄已是下拉選單，四種狀態都設好顏色

## 打開後要手動調的一件事

總覽表的「最近複習日」「下次複習日」兩欄目前顯示成數字序列值（例如 46239），選這兩欄 → 格式 → 數字 → 日期，改成日期格式即可正常顯示。

## 每次複習完的操作流程

1. 到 `複習紀錄表` 新增一列：填題號、日期、狀態，q 欄公式會自動算出（寫不出來=0、有Bug=2、超時=3、限時內完成=5）
2. 回 `總覽表` 找到這題那一列，「最近複習日 / 最近狀態 / 下次複習日 / 今日待複習」四欄會自動重算，不用手動動作
3. 手動更新 EF、n、Interval 三格為新值——用下面公式先算出來再貼上覆蓋舊值：

```
EF_new = MAX(1.3, EF0 + (0.1 - (5-q)*(0.08+(5-q)*0.02)))
n_new  = IF(q<3, 0, n0+1)
I_new  = IF(q<3, 1, IF(n_new=1, 1, IF(n_new=2, 6, ROUND(I0*EF0))))
```
（EF0 / n0 / I0 是這題目前在總覽表的值，q 是這次複習紀錄表算出的品質分數）

## 新增題目

在 `總覽表` 新增一列，填題號/題名/核心思維/難度，EF 填 2.5、n 填 0、Interval 填 1，H~K 欄把公式從上一列複製下來即可。
