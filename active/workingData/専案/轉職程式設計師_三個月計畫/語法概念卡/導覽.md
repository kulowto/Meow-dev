# 語法概念卡導覽

> **找卡片先看這裡，不要逐一開檔猜。** 這是索引，每張卡一句話摘要 + 主要關聯。

分兩個軸（依使用者的分類邏輯，見 `../(AI_Read) 知識庫重整規劃書.md` §二）：

- **軸一 方法論**：遇到題目，該往哪個方向想（什麼場景用什麼資料結構／演算法）
- **軸二 語法**：這個容器／語法具體怎麼用

---

## 拿到新題目的判斷流程

1. **先讀 `order_vs_value`**：答案跟「誰先誰後」有關嗎？有 → 保留順序的做法（單一掃描／Stack／雙指標）；無 → Hash / 排序類
2. **再讀 `container_selection`**：確定要用容器時，該挑哪一個
3. 確定演算法方向後 → 查軸一對應的方法論卡
4. 實作卡關 → 查軸二對應的語法卡
5. 收尾 → 比對 [`../跨題目盲點彙總.md`](../跨題目盲點彙總.md) 看有沒有重複踩同一類坑

## 軸二：語法

### 容器 API + 選擇邏輯

| 卡片 | 一句話 | 關聯 |
|------|--------|------|
| [`vector`](vector.md) | 動態陣列；多維索引層數；結構化綁定不支援；`while` 補大小；`depth++` 副作用 | `container_selection` |
| [`unordered_map`](unordered_map.md) | Hash 容器（含 `unordered_set` 章節）；`m[c]++`；erase 期間迭代；iterator 不支援 `<` | `order_vs_value`、`container_selection`、`map` |
| [`map`](map.md) | 有序 Hash（紅黑樹，原理在「底層機制」章節）；O(log n) | `unordered_map`、`order_vs_value`、`binary_search` |
| [`stack`](stack.md) | LIFO；`top()`/`pop()` 空容器是 UB；C# 的 `Pop()` 有回傳值 C++ 沒有 | `class_basics`、`order_vs_value` |

### C++ 語法

| 卡片 | 一句話 | 關聯 |
|------|--------|------|
| [`class_basics`](class_basics.md) | private/public、成員函式、成員變數 vs 區域變數（何時該用/不該用）、不支援巢狀函式 | `stack` |
| [`range_based_for`](range_based_for.md) | `for(T x : container)` 對應 C# foreach；值/參考/const 參考三種寫法 | `unordered_map` |
| [`linked_list`](linked_list.md) | 節點+指標；`&` 用錯地方；`list1` vs `list1->next`；dummy head；三指標反轉 | `floyd_cycle`、`order_vs_value`、`map` |
