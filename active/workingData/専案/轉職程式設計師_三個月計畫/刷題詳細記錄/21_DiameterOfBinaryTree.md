### 我的解法

```cpp
class Solution {
private:
    int res;

    int DFS(TreeNode* root){
        int DL, DR;

        if (root == nullptr){
            return 0;
        } else {
            DL = DFS(root->left);
            DR = DFS(root->right);
            res = max(res, DL+DR);
            return max(DL, DR) + 1;
        }
    }

public:
    int diameterOfBinaryTree(TreeNode* root) {
        res = 0;
        DFS(root);
        return res;
    }
};
```

- 時間複雜度：O(n)
- 空間複雜度：O(h)（h 為樹高，遞迴呼叫堆疊）

### 解題過程

#### 虛擬碼階段：三個環節依序釐清

1. 一開始想直接用「整棵樹最大深度 - 1」當答案，用自己畫的例子（`4,5` 掛在 `2` 下面、`2,3` 掛在 `1` 下面）反例驗證：整棵樹最大深度是 3，`3-1=2`，但正確答案是 3——因為直徑不一定通過根節點，也不是「樹高減一」這麼簡單，要在**每個節點**都各自算一次「左子樹深度+右子樹深度」，取所有節點裡的最大值
2. 一度把「回傳給父節點的深度」跟「拿去跟全域最大值比較的加總值」混在一起，經反例（左子樹深度跟加總值剛好不一樣的鏈狀樹）釐清：**回傳給父節點的永遠是深度，加總值只拿去跟全域最大直徑比較，不會被當成回傳值往上傳**
3. 全域最大值變數該宣告在哪這次自己主動答對：「計算在 DFS 內部，但變數宣告在外部，用於比對最終結果」——沒有重蹈前幾題「該跨層共用卻宣告成區域變數」的覆轍

#### 程式碼階段：C++ 不支援巢狀函式定義

一開始把 `DFS` 整個定義寫在 `diameterOfBinaryTree` 函式主體裡面，C++ 不允許在一個函式裡面直接定義另一個函式，編不過。改成把 `DFS` 獨立寫成 class 的 `private` 成員函式，`res` 也從原本 `diameterOfBinaryTree` 裡的區域變數改成 class 的成員變數，讓 `DFS` 這個獨立函式也能存取到它。改完邏輯沒再出錯，一次過。

### 1️⃣ 語法概念

- C++ 不支援巢狀函式定義（不能在一個函式內部直接寫另一個函式），需要跨函式共用的輔助邏輯要拆成 class 的另一個成員函式，搭配成員變數共用狀態
- 這題延續 Implement Queue using Stacks 學到的「成員變數 vs 區域變數」：`res` 需要在 `diameterOfBinaryTree` 呼叫 `DFS` 期間、以及 `DFS` 自己遞迴呼叫自己之間持續累積，只能宣告成成員變數

### 2️⃣ 邏輯與複雜度

- O(n) 時間（每個節點只走訪一次）、O(h) 空間（遞迴呼叫堆疊深度＝樹高）
- 核心關鍵：**用一次 DFS 同時完成兩件事**——回傳深度給父節點用、同時用左右深度加總去更新全域最大直徑，不需要對每個節點各自重新算一次深度（否則會退化成 O(n²)）

### 3️⃣ 演算法 / 資料結構盲點

- 「直徑不一定通過根節點」是這題最容易誤判的地方，直覺想「算整棵樹最深路徑」會漏掉不經過根節點、但更長的子樹內部路徑
- 「函式回傳值」跟「用來更新全域狀態的比較值」是兩件不同的事，這次差點混在同一個回傳值裡，之後遇到「遞迴函式需要同時做兩件事」的題目要先想清楚這兩者分開
